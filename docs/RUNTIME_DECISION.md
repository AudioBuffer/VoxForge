# 运行时链路决策

## 当前决定（2026-11）

**运行时出声只用 DSP，不接神经声码器。**

理由：

1. 我们的 DSP 输出的是**共振峰参数**（F1–F6 频率与带宽），属于频域的结构化表示
2. 梅尔谱是 80–128 个粗糙分档，把频域结构压平后再让声码器"猜"回来，等于先丢信息再补
3. 实测：NSF-HiFiGAN 重建后的音色会被拉向它的训练分布（真人歌声），听起来像另一把嗓子

## 允许出现的离线组件

| 组件 | 用途 | 是否进运行时 |
|---|---|---|
| NSF-HiFiGAN（54MB） | 离线实验中转波形 | ❌ |
| DiffSinger 声学模型 | 离线生成训练目标 | ❌ |
| librosa 梅尔 | 分析/对比 | ❌ |
| Klatt 核心（MIT） | 合成 | ✅ |
| 自研音高曲线 | portamento / 颤音 / bend | ✅ |
| 自研 G2P | 拼音 / 假名 → 音素 | ✅ |

## 如果将来要接声码器

必须让它工作在**频谱域**（幅度 + 相位），不能经过梅尔压缩。现有 Vocos 头（`vocos48_head.onnx`）就是梅尔→频谱的，方向也不对；正确做法是让网络直接预测残差频谱，再与我们 DSP 的输出相加。

## 教训

音色问题不要指望"套个声码器"解决。声码器负责的是"把参数变成波形"，不是"把粗糙变精细"。
