# 架构：潜空间扩散 + 声码器

## 管线

```
乐谱/文本
   │
   ▼
DSP 共振峰合成 ──► Mel 频谱 (128 × T)
   │                    │
   │                    ▼
   │              编码器 Encoder
   │                    │
   │                    ▼
   │              潜变量 z (C × T/4)
   │                    │
   │                    ▼
   │              扩散模型（在 z 上去噪，条件 = 乐谱/音素/音高）
   │                    │
   │                    ▼
   │              解码器 Decoder ──► Mel'
   │                                    │
   └────────────────────────────────────┴──► 声码器 Vocoder ──► 48kHz 波形
```

要点：

1. **扩散不在波形上做**。波形维度太高（48kHz 每秒 4.8 万点），扩散既慢又不稳。
2. **扩散也不直接在 Mel 上做**（128×T 仍偏大），而是先压到潜空间 `z`，时间维下采样 4 倍。
3. **声码器接收的是解码后的 Mel'**，不是原始波形；Vocos 这类模型本来就是 mel→波形。
4. **DSP 只负责给出起点**（带共振峰结构的 Mel），扩散负责把「机械感」改成「人声」，声码器负责最后的高频细节。

## 各部分职责

| 模块 | 输入 | 输出 | 现状 |
|---|---|---|---|
| DSP | 乐谱 | Mel（或直接波形） | ✅ 已实现（VoxSynth/src/dsp.h） |
| 编码器 | Mel 128×T | z C×T/4 | ⬜ 待训练 |
| 扩散 | z + 条件 | z' | ⬜ 待训练 |
| 解码器 | z' | Mel' | ⬜ 待训练 |
| 声码器 | Mel' | 波形 48k | ✅ Vocos 48k 已有 |

## 数据流约定

- Mel：128 bin，hop 256 @48kHz，log 压缩（与 Vocos 前端一致）
- 潜变量：通道数 32–64，时间下采样 4（即每 4 个 Mel 帧一个 z 帧）
- 条件：音素序列、F0 曲线、气声标签，在潜空间时间分辨率上对齐

## 回退路径

没有模型时：
- 编码器/解码器为空操作（z = Mel 的 4 帧平均，Dec = 4 倍上采样）
- 扩散为空操作（直接透传）
- 声码器用 Vocos（已有）或 Griffin-Lim

这样管线今天就能跑通，模型到位后逐个替换，不改调用方。

## 训练顺序

1. 编码器/解码器（自编码，先重建 Mel）
2. 扩散（在冻结的潜空间上）
3. 声码器微调（可选）

数据要求见旧项目归档的 `RESIDUAL_DATA.md` 与 `TRAINING_DATA_REQ.md`。

## 编解码器与 INN

- **512 → 256 的降维有损**，不可能严格可逆（INN 要求同维），所以编解码器用小型 1D 卷积，参数只有几十 KB
- **潜空间内的精修/去噪用 INN 仿射耦合层**（同维可逆），编码器与解码器共用一份权重，省一半参数
- **时间降采样用可逆 squeeze**（4 帧拼进通道），不丢信息
- 可逆性自测：`tests/inn_test.cpp`，256 维下 forward→inverse 误差 2.4e-7

## INN 的核心价值：训练显存与层数无关

可逆块满足「同维 + 严格互逆」，因此反向传播不需要保存中间激活：
从输出逐层 `inverse` 还原即可，只保留当前层的少量隐藏量。

实测（`tests/inn_stack_test.cpp`）：

| 层数 | 参数 | 互逆误差 | 存储缓冲 |
|---|---|---|---|
| 1 | 49,536 | 2.4e-7 | 512 float |
| 4 | 198,144 | 7.2e-7 | 512 float |
| 8 | 396,288 | 9.5e-7 | 512 float |
| 16 | 792,576 | 1.2e-6 | 512 float |

层数翻 16 倍，激活存储不变——这就是能在手机上训练深层网络的底气。
